# 🔍 Website Auditor Tool

A lightweight, full-stack SEO & performance audit tool built with Node.js, Express, Cheerio, and vanilla frontend web technologies. It accepts a target URL, scrapes its HTML, and returns key metrics like response time, heading structures, metadata completeness, and alt-tag coverage.

---
